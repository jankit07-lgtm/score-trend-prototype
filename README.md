# StonksAI · Weekly score trends prototype (Ultra)

Clickable prototype of the Stocks page Weekly Scores card with 12-week trends for FQS, TMS and DVES,
the full trend sheet (12W / 26W), the Free/Pro upsell state, and the Alert for My Stock "Watch" sheet.

Mock data only. Use the Plan and Stock switches beside the phone to walk through the demo cases.

## Run locally
    npm install
    npm run dev

## Deploy
Vercel: framework preset Vite, build `npm run build`, output `dist`.
